# Millwork shop outreach kit

Solicitation material for architectural millwork shops, hospitality casework
fabricators, luxury residential joinery firms, and stair companies nationwide.
Pairs with the landing page at `/millwork-shops` on uniquewoodproducts.com.

Brand: UWP Brand Standard v7. Teal `#124E53`, warm white `#F7F4EF`, soft black
`#212223`, earth gold `#C9A96E` (seal moments only). Outfit for everything;
Cormorant Garamond for display only. Tagline exactly `MOULDING · STAIR PARTS · MILLWORK`.

## Files

| File | Use |
|---|---|
| `email-01-intro.html` | First touch, HTML. Table-based so it renders in Outlook. Swap the `{{...}}` fields. |
| `email-01-intro.txt` | Same message, plain text. Use this for cold sends; plain text lands in the inbox more often. |
| `email-02-followup.txt` | Day 4. One profile, one ask. |
| `email-03-breakup.txt` | Day 10. Closes the loop without begging. |
| `capability-sheet.html` | One-page 8.5×11 capability sheet. Open in a browser, print to PDF at 100% scale, attach to email 2. |
| `linkedin-connect.txt` | 300-character connection note for the shop's purchasing manager or estimator. |

## Sequence

1. Day 0: `email-01` to the purchasing manager or chief estimator. Not the owner unless the shop is under 20 people.
2. Day 4: `email-02` with `capability-sheet.pdf` attached and one specific profile from their published work named in the subject line.
3. Day 7: phone call. Ask one question: "What profile are you running next week that you would rather not run?"
4. Day 10: `email-03`.
5. Every 60 days after: one photo of a run on the outfeed, no ask.

## Merge fields

`{{first_name}}` `{{shop}}` `{{city}}` `{{project_or_profile}}` `{{rep_name}}` `{{rep_title}}` `{{rep_phone}}` `{{rep_email}}`

## Rules

- Name the branch: NW Houston / Tanner Rd. Never "warehouse", "plant", "shop", or "yard".
- One ask per email. The ask is always a profile drawing, never "a meeting".
- No claims we cannot document. No AWI QCP, FSC, or fire-rating claims unless the paperwork exists.
- Subject lines under 45 characters. No exclamation points.
